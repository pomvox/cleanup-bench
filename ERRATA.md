# Errata: retired items

Items are retired, never edited. A retired item keeps its id and its line in
the item file with `status: retired`, `retired_in` and a link to the issue
that decided it; it is excluded from scoring from the bench version named in
`retired_in` onward. Every retired item is listed here with the date, the
issue link and the reason. Published rows for earlier versions are unchanged.
A replacement item may be added under a new id in the next version. The
process is in `GOVERNANCE.md`; the site reads this table for its "Retired
items" section.
